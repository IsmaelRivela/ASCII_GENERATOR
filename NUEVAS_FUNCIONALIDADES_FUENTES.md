# 🎨 Nuevas Funcionalidades - Selector de Fuentes

## ✨ Cambios Implementados

### 🔤 Selector de Fuentes
- **Nueva funcionalidad**: Puedes alternar entre las fuentes Tulipana y Rushmore
- **Ubicación**: Selector de radio buttons justo debajo del campo de caracteres ASCII
- **Opciones disponibles**:
  - 🎨 **Tulipana**: Fuente original del proyecto
  - 🎨 **Rushmore**: Nueva fuente Rushmore-Gliphs

### 🔄 Cambio Automático de Caracteres
- Al seleccionar una fuente diferente, los caracteres por defecto se actualizan automáticamente
- Cada fuente tiene sus propios caracteres recomendados por defecto
- Los presets de caracteres funcionan con ambas fuentes

### 🎯 Funcionalidades Mejoradas

#### Para Imágenes PNG:
- La fuente seleccionada se aplica automáticamente
- El mensaje de estado muestra qué fuente se está usando
- Compatible con todas las escalas de resolución

#### Para Archivos SVG:
- La fuente seleccionada se embebe en el archivo SVG
- Garantiza la compatibilidad con software como Adobe Illustrator
- Mantiene la escalabilidad infinita

#### Preview en Vivo:
- Funciona con ambas fuentes
- Se actualiza automáticamente al cambiar la fuente
- Muestra los resultados en tiempo real

## 🚀 Cómo Usar

1. **Subir una imagen** como siempre
2. **Seleccionar la fuente** usando los botones de radio:
   - Tulipana (por defecto)
   - Rushmore
3. **Los caracteres se actualizan automáticamente** al cambiar la fuente
4. **Generar** tu ASCII Art con la nueva fuente

## 💡 Tips

- **Experimenta** con ambas fuentes para ver cuál se adapta mejor a tu imagen
- **Los caracteres por defecto** de cada fuente están optimizados para esa tipografía específica
- **Puedes personalizar** los caracteres manualmente después de seleccionar la fuente
- **Los presets** (Tulipana, Flores, Bloques, Clásico) funcionan con cualquier fuente
