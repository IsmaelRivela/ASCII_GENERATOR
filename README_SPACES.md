# ASCII Art Converter PRO

🎨 Convierte imágenes a arte ASCII en alta resolución (PNG) o formato vectorial escalable (SVG).

## Características principales

✨ Múltiples formatos de salida (PNG, SVG, TXT)
🖼️ Preview en vivo
🎯 Sistema de capas para fotografías
🔄 Modo aleatorio para logos
📐 Alta resolución (hasta 10x para impresión)
🎨 Fuente IcoMoon personalizada con glifos únicos

## Uso rápido

1. Sube una imagen
2. Selecciona preset "IcoMoon" para glifos personalizados
3. Ajusta parámetros al gusto
4. Genera y descarga tu arte ASCII

¡Ideal para crear arte único y escalable!
